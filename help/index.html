02 · SETUP

Installation

Install on XAMPP

  1. Place the project folder inside xampp/htdocs/.
  2. Start Apache and MySQL.
  3. Create a database named paper_cast in phpMyAdmin.
  4. Import database/schema.sql.
  5. Copy config/database.example.php to config/database.php and enter your local credentials.
  6. Open http://localhost/paper-cast/.
Installation · 5 min read

Import the database

In phpMyAdmin, select the paper_cast database, choose Import, select database/schema.sql, and run it. The schema creates the categories and posts tables and inserts sample content.

Database · 3 min read

Configure database access

Copy the example config to config/database.php. Set the host, database name, username, and password to match your MySQL setup. Never commit real credentials.

Configuration · 3 min read
03 · SETTINGS

Configuration

Customize the appearance

Edit assets/css/style.css to adjust colors, spacing, typography, and responsive layouts. Shared page layout is in includes/.

Design · 3 min read

Production security

Use a dedicated database account with limited privileges, HTTPS, regular backups, and server rules that block direct access to configuration and SQL files. Never expose database credentials.

04 · EDITORIAL

Publishing

How articles work

Articles are stored in the posts table. Each post has a title, unique slug, excerpt, content, optional cover image, category, and publication status.

Articles · 3 min read

Drafts and published posts

The public homepage and article detail page currently display posts with status published. Draft posts remain hidden from public pages.

Categories

Categories organize stories by topic. Add or edit records in the categories table. Each category needs a unique slug.

06 · SUPPORT

Troubleshooting

Database connection error

Confirm MySQL is running, the database exists, credentials in config/database.php are correct, and PDO MySQL is enabled in PHP.

Common issue · 2 min read

Article not found

Check that the article exists, its slug matches the URL, and its status is published. Draft articles are hidden from public pages.

Common issue · 2 min read

Blank page or PHP error

Check the Apache/PHP error log. During local development, enable errors locally; turn detailed error output off on production sites.

Project structure
